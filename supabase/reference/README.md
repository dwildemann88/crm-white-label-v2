# Referência do ambiente atual

Arquivos exportados por consultas somente de leitura no Supabase.

Eles servem para análise e comparação. Não são migrations executáveis e não devem ser importados diretamente no banco.

Conteúdo:

- funções públicas e privadas;
- policies e estado do RLS;
- privilégios de coluna do perfil;
- triggers;
- índices;
- constraints.
