CRM COMERCIAL V5.2 — LEIA ANTES DE EXECUTAR

1. Extraia esta versão em uma pasta nova. Não copie arquivos por cima de versões anteriores.
2. Copie seu .env.local funcional para a raiz. Ele não acompanha o ZIP.
3. A V5.2 substitui o Make somente no transporte do WhatsApp. O cenário de Facebook Lead Ads continua separado.
4. Execute:
   npm install
   npm run verify
   npm run typecheck
   npm run build
5. Aplique primeiro as migrations da V5.1 e depois `202608050004_whatsapp_cloud_direct.sql`.
6. Cadastre as secrets e publique as Edge Functions conforme `docs/WHATSAPP-CLOUD-DIRETO.md`.
7. Valide em URL de prévia antes de publicar em produção.
8. Teste obrigatoriamente: login, leads, Kanban, perda, venda, transferência, relatórios, chat, texto, mídias, templates e status.
9. Mantenha os cenários antigos do WhatsApp no Make como rollback até concluir a homologação.
10. O sistema visual é fixo. Cada organização altera somente nome e logo.
11. Nenhuma migration ou Edge Function é aplicada automaticamente por este pacote.
